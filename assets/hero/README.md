# Hero 3D assets

Everything the live Hero loads, generated from the files in this folder. ADR 0002 sets the route, budgets and licensing rules.

```bash
bun run assets:hero
```

`scripts/build-hero-assets.ts` runs the whole pipeline:

1. Rasterises `label-so-o-coco.svg` to a 2048 × 1024 PNG in headless Chromium, with the fonts beside it.
2. Runs `build_hero.py` in Blender headlessly to build the coconut, its halves and the can, export them as GLB, and render the poster.
3. Optimises both GLBs with `gltf-transform optimize --compress meshopt --texture-compress ktx2`. The extra flags keep the named nodes, the materials and the can's label UVs, and stop the halves' crack edges being simplified off the whole coconut.
4. Encodes the label as UASTC KTX2 (zstd, with mipmaps).
5. Copies three's Basis transcoder (`basis_transcoder.js` and `.wasm`), so the decoders are self-hosted.
6. Checks the triangle and texture budgets and fails the build if any is missed.

The outputs go to `public/hero/` and are committed. Intermediates go to `assets/hero/.build/`, which is ignored.

## Requirements

- **Blender 5.2+.** The script finds it through the `BLENDER` environment variable, then `blender` on `PATH`, then the default Windows install path.
- **KTX-Software 4.4+**, with its `ktx` CLI on `PATH`.
- **Playwright Chromium** (`bun run test:e2e:install`).

## Sources

| File | What it is |
|------|------------|
| `build_hero.py` | Blender Python script. It lathes the can and adds its tab, with one rectangular UV strip on `Body_Label`. It shapes the whole coconut and paints its husk texture procedurally. It cuts the halves with a jagged boolean, lines them with a white flesh shell, and pivots both halves on the crack line. It renders the poster. |
| `stage.json` | The camera, lights and first-frame pose, shared by the poster render and the live scene (`components/hero-scene.tsx`), so the poster is the first 3D frame. |
| `label-so-o-coco.svg` | The Só o Coco can label (DESIGN.md § Can label: Barraca). The back-panel wording is a placeholder until the Copy ticket approves it. |
| `fonts/` | Bowlby One and Figtree, used to rasterise the label. |

## Licences

- **Coconut, halves, can, label and poster**: our own work, generated by the scripts in this folder. No third-party models are used.
- **Fonts**: Bowlby One and Figtree are under the SIL Open Font License 1.1 (`fonts/OFL-*.txt`). They are used here only to rasterise the label.
- **Basis transcoder** (`public/hero/basis/`): from three.js (MIT), version-locked to the installed `three`.

No Editorial, NC or ND models and no free-tier AI output are used (ADR 0002).

## Outputs and budgets

| Output | Contents | Budget |
|--------|----------|--------|
| `coconut.glb` | Nodes `Coconut` (whole), `Coconut_Top` (the machete cap) and `Coconut_Bottom`. The halves pivot on the crack line at the back. Materials `Husk`, `Husk_Inner` and `Flesh`. | 10–25k triangles; textures 1–2k |
| `can.glb` | Nodes `Can` and `Tab`. Materials `Body_Label` (the label UV strip, with no image) and `Metal`. | 2–6k triangles |
| `label-so-o-coco.ktx2` | The Só o Coco label, swapped onto `Body_Label` at runtime (`flipY = false`, sRGB). | 2048 × 1024 |
| `poster.png` | The first 3D frame, 1024 × 1024 with a transparent background. | |
